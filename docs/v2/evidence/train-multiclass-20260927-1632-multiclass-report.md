# 第 8b 步：T2 多分类（D1 子集，10 类 attack_cat）

数据：官方训练文件，训练分区 149,039 行、验证分区 26,302 行；V0 的 42 个特征；树模型用 P1，MLP 用 P7。官方测试文件（锁定 holdout）未读取。
类别不平衡用平衡类权重；SMOTE 做法把训练分区中少于 5,000 条的类别用 SMOTE-NC 合成到 5,000 条（只作用于训练行，预处理器只在真实行上拟合）。
不做超参搜索：XGBoost/RF/MLP 复用 T1 调优参数，LightGBM 复用 T1 初筛参数。判定取 argmax。XGBoost、LightGBM、MLP 用验证分区早停，指标偏乐观。

训练分区类别分布：Normal 47,600，Analysis 1,700，Backdoor 1,484，DoS 10,424，Exploits 28,384，Fuzzers 15,456，Generic 34,000，Reconnaissance 8,917，Shellcode 963，Worms 111。
