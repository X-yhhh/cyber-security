# 阶段 2 验证集基线与门槛确定方法 v2

本方法在读取任何 CIC-IDS2017 validation 模型结果之前固定。只运行当前 `unsw-binary-2026.10.2` 的冻结 ONNX（SHA-256 `c87b883d0ac32b0a827441eb5d97164acaa46e67653fb79cd369b9c794949358`），不拟合、不重选模型阈值，不读取 holdout 或 CSE-CIC-IDS2018。交付 fixtures 冒烟不属于数据集评分。

## 数据门禁

五天均须完成原件哈希、日期、链路及公开攻击时段/端点的交叉核验。冻结规则为 `label-rules-cic2017-v1.json`，以 `label-freeze-v1.json` 的 SHA-256 绑定；本轮用户明确允许以只读文件和哈希替代提交，审计后再提交。

使用日期 + 无向五元组分组，合并精确/六位小数近重复所在连接组后去除精确重复；冲突标签全部排除。按日期和类别对组进行固定种子 70/15/15 分配。仅两台服务器，不能声称独立主机泛化；日期分层也不等于未来时段评估。除用户明确批准列为不可评估的 Heartbleed 外，全部规则攻击类别须在各分区出现，包括完全被过滤掉的类别。范围由 evaluation-scope-v1.json 及其 SHA-256 绑定；Heartbleed 保留标签和缺口证据，但不计入本轮训练、指标或验收范围。缺失时保留 `blocked_category_coverage`，不得拆开长连接或删除要求来制造通过。

holdout 只生成并记录统计/指纹，不执行预测；POSIX 上设置 000 只是一层误读防护，不是对文件所有者的密码学隔离，Windows 以流程门禁和追加审计约束。切分临时索引成功后删除，避免留下可直接读取的 holdout 副本。没有提供解锁命令。

## 数值方法

Normal 至少 1000 条、Attack 至少 100 条 validation 样本，且切分门禁通过，才允许正式冻结门槛。使用二项分布 Wilson 95% 区间，控制正常样本误报率的不确定性并对攻击召回给出保守估计。

- L2 良性 FPR 上限：`clamp(1.5 × validation FPR 区间上界, 1.5%, 5%)`，向上取千分位。1.5 倍留出域偏移余量，5% 是不可超出的操作上限；即使基线更差也不放宽。
- L2 攻击召回下限：`clamp(0.9 × validation recall 区间下界, 80%, 95%)`，向下取千分位。10% 作为域偏移容差，80% 是最低要求；差基线不能把要求降到 80% 以下。
- L3 新时段良性 FPR 上限：`clamp(validation FPR 区间上界, 0.5%, 3%)`，向上取千分位；至少 1000 条正常样本。受控流量应更严格限制误报，3% 为上限。

这些常数是本项目预先确定的验收选择，不是数据集作者结论，也不保证新模型会通过。若样本数或类别覆盖不足，仍输出诊断基线，但拒绝生成“正式冻结成功”文件。不能将缺失类别计为零漏报，也不能把验证集指标当 L1 锁定评估结果。

## 恢复模型触发

L1 每个数据集分别满足 Macro-F1 ≥ 0.92、FNR ≤ 5%、FPR ≤ 1.5%、PR-AUC ≥ 0.93、ROC-AUC ≥ 0.99；L2/L3 全部达标、样本数足够且范围已声明；标签/切分/制品哈希一致；后端接入五项验收通过；另行独立批准新响应策略并显式启用模型触发。任一未知或未覆盖条件均不恢复。阶段 2 不执行这些未来验收，不激活模型，不启用防火墙。

## v2 变更依据

用户在本会话明确批准 Heartbleed 不可评估例外。v1 保留不改；v2 仅收窄类别覆盖范围，不改变数值公式，不改变冻结标签规则、不拆分长连接。冻结时 CIC validation 评分次数仍为 0。
