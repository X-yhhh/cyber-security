# P1 标签与抽查策略

版本：p1-label-policy-v1，2026-10-03。对应[数据方案](../数据与模型方案.md)和[检测契约](../检测与处置契约.md)。本策略用于可行性审查，不是训练标签或发布资格。

## 来源与许可

仅使用 IoT-23 官方列出的完整场景及对应 `bro/conn.log.labeled`，不下载或执行恶意软件。引用 Garcia、Parmisano、Erquiaga（2020），IoT-23 v1.0.0，DOI `10.5281/zenodo.4743746`。版本化 Zenodo 记录为开放数据、CC-BY-4.0；镜像顶层 README 链接 CC-BY-2.0，部分旧场景 README 仍写需要单独许可。采用发布者对该命名数据集的公开许可，并保留文字差异；不把此许可扩展到其他目录或二进制。正式再分发前另核对许可归属和引用。

镜像的场景 34-1 标签最后修改于 2023-12-12，字段名为 `det_label`；3-1、8-1 为 2019-12-25 的 `detailed-label`。二者显式解析并登记文件哈希，不宣称镜像逐字等于 Zenodo 2020 冻结包。正式训练版本须绑定实际镜像文件和标签修订。

## 标签语义

- `Malicious`：保留发布者详细标签和 `publisher_documented` 证据层级，不将所有感染主机连接批量标攻击。
- `Benign` 且详细标签为 `-`：按发布者良性标签审查，不从未匹配规则自行产生正常标签。
- 其他标签为 `unknown`；无法关联、零包计数冲突、关联重叠或坏头部是独立诊断，不进入可用正负计数。
- `PartOfAHorizontalPortScan` 是扫描连接标签。跨不同 peer 的连接不能汇成一个 `peer_service` 执行证据，尚未证明窄规则能覆盖扫描，保留告警研究资格。
- `DDoS` 不能直接证明主机具备 DDoS 防护。34-1 本次抽查存在计数/连接定义问题，先修复关联，不能据标签直接训练自动阻断。
- `C&C` 保持原标签，仅为完整连接研究候选；不机械改名为 `connection_abuse`，不由类别名推定头部特征已能区分正常定时服务。

## 抽样与关联

每场景抽查 30 条独立发布者 UID。以 `SHA256(scenarioId + NUL + uid)` 稳定排序，先各取 10 条 TCP/UDP 正负例，其余 10 条优先覆盖缺时长、无反向包、非 TCP 和未知标签；不足时保留实际数量。选择不使用关联结果、模型分数或最终指标。

本轮最初用全协议正负层抽查 3-1 时，有 3 条 ICMP 未关联。原因是 Zeek ICMP 的 type/code 不能用 TCP/UDP 端口解释。修订为支持协议正负层，并将 ICMP 明确列为 unsupported；初次结果保存在本机忽略的审计目录，没有改写发布者标签。未来需要 ICMP 时新增对应关联实现和测试。

TCP/UDP 关联使用五元组、发布者起止微秒时间和 ±1ms 容差，分别核对 originator/responder 包计数。时间窗重叠为 `ambiguous`，计数/头部/采集点不一致为 `inconsistent`，没有包为 `unmatched`。报告保留全部样本及失败；抽样通过不证明全量通过。1ms 容差对快速重复 SYN 可能过宽，34-1 必须用精确时间和握手 epoch 进一步裁决，不能直接缩小容差后宣布成功。

本机锚点取各场景发布者记录，仅在本地进程内使用。报告保存锚点摘要、连接摘要、计数和质量，不保存原始端点或载荷。只有首个已关联 TCP 包为纯 SYN、锚点有效且关联无歧义时，才标记 IPv4 对端/服务元数据可构造。这不是现场有效 `targetRef`，不含本机租约、授权或执行凭据。

## 因果与活动边界

本轮所有攻击标签为 `final_only`：标签文件没有提供可复核的攻击开始时刻。1s/5s 头部参考值只使用截止点前的包，但关联和参考排序属于离线审查；没有实现 P2 的水位、Tick、parentConnection、1/5/30s 上下文或 live 对拍，不能把这些参考值投入训练或早期自动阻断验收。

3-1、8-1、34-1 是不同日期的感染/捕获活动，不把同一捕获切段当独立活动。C&C 具有多捕获候选，水平扫描有 3-1/34-1，DDoS 目前只有 34-1。尚未分配 final_test；先修正任务定义、关联及 prefix 起点，再按活动分区，保留至少 150s 上下文隔离带。整个捕获内多次连接并不代表多次独立感染活动。

## 下一项实验

1. 用 34-1 原始包、精确时间和 TCP SYN/重传/epoch 定义复核 12 条歧义样本及发布者零计数；确认标签版本或生成可追溯修订，不原位改旧标签。
2. 对目标家族逐活动登记攻击起点和同服务困难良性任务；没有起点继续限定 final 研究。当前 IoT 良性连接不能替代桌面下载、更新和正常并发验收。
3. CIC 修正版需先恢复原始 PCAP 获取并核验完整有界场景；328M 的修正表格包不能提供 prefix 原始证据。
