这只是**未标注 pilot**；不能据 ready 数宣布 A3 无异常通过，超 MTU/拒绝计数仍需分析，不能提高 MTU 或改变冻结特征来消除拒绝。handshakeSeen 在当前实现表示初始 SYN 可见，不保证三次握手完成。

实质阻塞是标签：

1. 官方 AIT-NDS 的 `2_label_logs.ipynb` 部分逻辑仅按攻击起止时间给剩余流赋攻击标签；正常端口/角色先分配类别。直接复用会造成漏标/错标，本轮只阅读代码，未执行。
2. 官方配置的攻击者 `vpn_ipv4_address` 与 vpn 主机地址相同；受害机看到的是共享出口。3832 个入站初始 SYN 中，2665 个来自这个 VPN 出口。不能把该 IP 的所有连接都认定为攻击者。
3. PCAP 在官方 Webshell 上传时段确有 1 个初始 SYN，目录扫描与 WPScan 时段也有流量；这只是时间重合，**不等于已经证明这些流全部属于攻击**。需要攻击侧捕获/连接映射或独立应用日志的可判定关联，无法消歧的记录必须 excluded；不能把不确定记录补成 Normal。
4. 从多观测点汇总的 NDS 还可能重复同一连接，应按会话/主机/网络分组去重，再切分；本项目重新提取时优先受害主机单观测点。

结论：保留为优先替代候选，**尚不正式采用其训练标签**。完整脱敏计数见 [ait-audit.json](phase2-evidence/ait-audit.json)。
