## 3. P3-A 的诊断和裁决口径

逐观察记录去敏目标键、activity/capture/parent/observation引用、事件时刻、原始及校准分数、阈值、最新 parent 替换、证据年龄、末包年龄、窗口覆盖、合格独立连接数、证据跨度、对端新连接数、TTL覆盖区间和资产动作预算。保留全量门槛状态及确定性的首个拒绝原因；未到达的有状态门槛标未检查，不伪造多个实际拒绝。

逐机会以冻结分母为入口，归并为已覆盖、迟到覆盖、未覆盖或证据不可评估，附相关观察与候选动作引用。必须区分：

- 低分、证据超过10秒、末包超过15秒、5秒上下文不足、独立parent不足和证据跨度不足；不要合并成 `insufficient_distinct_fresh_evidence` 后就结束分析。
- 新连接速率不足、资产同时规则/每分钟动作预算、连续阻断上限，以及同目标TTL内去重。TTL抑制可能表示已有动作覆盖，不能直接算漏报；反之不能因有动作就默认覆盖整个活动。
- final机会的混合标签按历史保守口径单列；新起点评估的 Unknown 按预登记规则单列，保留不可评估/排除总数，不能跨版本无说明地改变分母。

报告同时保留原始模型工作点、校准后模型工作点和冻结完整策略结果；按角色、来源、独立活动、声明场景输出，不把快照拒绝次数直接当漏阻断机会数。逐机会明细只存受控忽略目录，Git仅保存去敏摘要、计数、代码/数据/策略哈希。

冻结组合的回归覆盖所有开发活动：train仅诊断，选型及校准角色用于识别回归且注明各自选择暴露，独立开发评估角色另列。先在原时序和完整资产预算域回放，再按活动/来源汇总，不能先拆成各来源各自重置预算来制造通过。每次修改策略或校准均生成新组合并重跑回归，不能重选阈值后还称原冻结组合。

后续阶段裁决至少分别输出：`SELECTION_COVERAGE_BELOW_TARGET`、`FROZEN_POLICY_SCENARIO_COVERAGE_BELOW_TARGET`、`MISSING_QUALIFIED_ONSET_AND_PREFIX`、`INSUFFICIENT_INDEPENDENT_ATTACK_ACTIVITIES`、正常机会不足和最终测试未分配。以上是待实现的原因分类；缺证据、代码未完成和实测失败分列，不改写历史JSON。历史19/28及本轮4/28都不足80%，原阶段仍blocked。

验收包括冻结4/28复现、校准81/84不能掩盖选型失败、同parent新快照替换、过期高分、上下文未热身、跨目标/epoch隔离、TTL已覆盖与真漏报区分、预算竞争及TTL内附带误伤。使用现有测试扩展这些行为断言，不以只验证字段存在替代统计回归。P3-A完成不自动启动训练。

## 4. P3-B/C 的数据资格与独立评价

1. 2017 Slowhttptest 和2018 Slowloris分别核对发布者工具模式、可观察起点和窗口；不能把2017 Slowloris的未完成HTTP头规则通用于所有慢请求模式。20条抽查是可行性闸门，不是全量标签批准。完整连接用于核验谱系，任何prefix特征与起点判断不得借用asOf之后的信息。
2. 已有669条prefix、124个parent仅来自训练侧的同一活动。新数据同时需要各角色合格的攻击prefix与同服务正常prefix；禁止把起点之前的Unknown当良性，也不能把final标签反向铺满整个连接。
3. 建立capture、原始activity、完整parent、重放/近重复的关联组；有关联的组整体分区。至少150秒上下文隔离带及重置引擎仍适用，跨界长连接整体归组或排除；背景时间桶不是新的独立任务。
4. 保持训练、模型选型、校准/策略选择、独立开发评估职责分开。数据足够时使用独立分组留出；数据有限可预登记分组交叉拟合，但每个评分组必须同时排除在该折的模型/预处理拟合、校准和策略选择之外，调参需要内层分组。汇总折外结果不等于最终冻结单个候选已通过P6。
5. 独立开发评估以至少5个独立攻击活动组及至少5个独立良性活动组起步，按声明场景列实际组数；每个声明场景都须有未参与该评分组合选择的证据。5组只是开始估计聚类区间的最低计划数，不证明统计充分或99%精确率。组数不足则报告不可可靠估计，不能靠拆分capture补齐。
6. 若后续根据独立开发评估结果修正模型/策略，该集合已暴露，登记为开发诊断；新一轮独立评价须重新安排未参与修正的组。final_test由另一未暴露活动集合承担，P3只登记来源、分区和保管哈希，不用测试特征或标签选择方案。
7. prefix数据版本必须绑定来源/许可、起点规则、标签、分区、近重复、各角色正负/parent/活动计数、质量、提取器/profile和哈希。复用未变的rc.2提取器与已定义prefix语义；字段、公式或输入形状改变才返回P2升级契约并复算/对拍。旧final研究集保持可复现。

≥100个支持范围攻击episode、≥3000个良性机会仍是P6/P7统计验收底线，不要求P3启动训练时已达最终样本量；也不能将现有final机会冒充正式起点episode。P3-C须证明补齐路径可行并登记缺口，未具独立证据时仅允许有界探索，不通过P3可行性出口。

## 5. P3-D 的模型和策略预算

默认不重跑旧final的三算法完整矩阵；MLP已有对照结果，时序E4仍须先证明必要性并冻结输入。新一轮完整模型拟合上限分配如下，折内训练、失败重跑也计数：

| 用途 | 最大完整拟合数 |
|---|---:|
| LightGBM/XGBoost × 基础/基础＋对端上下文，各固定种子42 | 4 |
| 最多两项根因修正或必要消融 | 2 |
| 固定优胜方案补种子43/44，只报告方差，保留42 | 2 |
| 分组折内复核或失败重跑预留 | 2 |
| 合计 | 10 |

优先采用分组留出控制预算。若交叉拟合/嵌套选型超出预留，在训练前缩小矩阵或单独登记预算变更，不把多折训练算成一次。小批冒烟另限3次，其他拟合（来源诊断、校准器及其折数）逐项登记，不能借“非完整训练”无限搜索；树模型单次上限300秒，整轮训练/选择墙钟上限4小时，累计GPU占用不超过4小时，均记录实际设备与失败耗时。

固定误伤预算为：开发评价零正常机会误伤、零错误候选动作；同时比较仅规则、仅模型和模型＋策略，三者共用目标、时序、保护边界、TTL及资产预算。模型贡献按相同独立评价组的配对结果和聚类区间报告，区间跨零须写明收益未确证。逐声明场景完整策略覆盖目标至少80%；无合格起点时只报final诊断，不能借该指标通过prefix可行性。

策略搜索先登记阈值/连接数/跨度/上下文/TTL的有限网格、候选总数及校准选择方法；选型活动上的冻结回归失败不能用校准高分抵消。新连接速率可能不适配长期维持的慢请求，在独立困难良性上比较保留/移除或改用已冻结可观察证据；移除该条件只作待验证候选，不能用本轮13/28的开发诊断直接批准。对端上下文与主机全局/来源特征分开消融，继续报告来源可分性与同服务正负对照。

交付需含候选组合哈希、每角色/场景回归、独立组结果、E5、错误归因、资源、实验预算台账及跨平台ONNX对拍。ONNX最大分数差≤1e-4，阈值附近决策0翻转；prefix输入、mask、类别词表、预处理和校准全部绑定，旧final对拍不能替代新候选验证。

正式时效由标签依据确定起点、按真实流量时序回放，并验证适配器对新建/已建立连接的实际效果。没有可执行引用的research观察只产生诊断候选；网络层隔离的无害canary用于P5/P7，不向网卡注入攻击流量。ONNX耗时和final快照输出时间都不能代替真实动作延迟。
