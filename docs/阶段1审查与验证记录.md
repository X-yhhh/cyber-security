| 发现 | 影响 | 已处理 |
| --- | --- | --- |
| manifest 的范围列表类型错误被解释为空、不限制范围 | 交付包校验无法 fail-closed | 缺省兼容；显式错误类型、null、空数组拒绝，增加回归测试 |
| 聚合上下文超过 100,000 条时静默截断 | 高流量窗口可能漏报而消费仍成功 | 多取一条检测上限，超限抛稳定异常、整批回滚，禁止写部分告警 |
| 窗口抑制在消费事务使用普通快照读 | 已有 RR 快照看不到其他事务刚提交的告警 | 资产统一升序加锁，窗口/告警当前读；并发提交后旧快照测试通过 |
| 按每条规则分别锁资产；用户冻结与改角色锁顺序不统一 | 反向锁序死锁、并发管理员状态变化 | 分别统一锁序；管理员变更以稳定角色行串行化并重新核验操作者仍 active；双管理员互相冻结只成功一方 |
| 新密码按字符长度校验，未处理 BCrypt 字节上限 | 中文或长密码导致编码异常或不一致 | 创建/重置/自助改密统一拒绝 UTF-8 超过 72 字节，返回 400 且原口令不变 |
| 映射批准未填写 V17 审批决定列 | 新审批台账信息不完整 | 批准同时写 reviewed_by/at，保留 approved_by |
| 详情请求晚返回覆盖新选中的用户/资产/数据源/传感器 | 显示错误记录，后续操作可能作用于错误对象 | 请求序号与当前 ID 双校验；传感器加载先清旧对象；切换对象时清一次性凭据 |
| 关闭抽屉后口令残留 | 下次打开复用敏感表单状态 | 关闭自助改密、用户详情、新建用户时清空口令 |
| 规则名称/原注释声称确认登录失败、Web 路径探测 | 超出无载荷 v4 的识别能力 | 保留稳定 ruleKey，原因和文档改为流特征代理，明确无端口计数与登录日志证据 |
| 撤销单条资产授权后提示“整个资产立即失效” | 存在其他有效授权时提示不准确 | 明确仅该授权撤销；无其他有效授权时 fail-closed |
