# 功能模块设计

## 1. 角色

| 角色 | 权限范围 |
| --- | --- |
| 平台管理员 | 用户/角色、系统配置、资产和数据源登记；不能绕过执行策略 |
| 安全分析员 | 查看授权范围内的告警/事件、调查证据、标注结论、提交处置建议 |
| 响应审批员 | 审批需人工确认的动作、查看目标和影响、批准/拒绝并填写原因 |
| 模型管理员 | 登记、校验、审批和切换模型版本；不能因此获得资产处置权限 |
| 审计只读用户 | 查看授权范围内的审计和复盘记录，不可更改数据或执行动作 |
| 连接器身份 | 仅向指定数据源/租户写入约定类型的数据，无控制台登录权 |
| 响应适配器身份 | 仅调用策略授予的特定资产动作，无通用管理权限 |

高影响操作遵循职责分离；提交人与审批人默认不得为同一用户。角色权限还需受资产范围限制，不能仅靠全局角色授权。

## 2. 模块划分

### 2.1 身份、角色与授权范围

- 登录、会话、角色/权限配置、API 客户端身份及连接器凭据引用管理。
- 为用户、数据源、资产和执行适配器绑定范围；范围变更产生审计记录。
- 支持冻结用户、轮换客户端密钥引用和紧急撤销处置授权。
- 验收：未授权用户不能枚举或操作范围外资源；连接器身份不能调用处置接口。

### 2.2 资产与授权登记

- 维护资产标识、类型、环境、关键性、标签、所有者、授权状态及生效/到期时间。
- 将靶场资产与授权实网资产分区标记；处置策略只引用已登记资产/标签。
- 保存授权证明的安全引用和审批记录，不在普通业务字段中保存敏感证明原文。
- 验收：授权过期、资产停用或靶场边界变化后，相关自动动作被拒绝。

### 2.3 数据源与接入批次

- 管理公开数据集、文件导入、回放源和授权被动遥测连接器。
- 记录字段清单、模式版本、授权范围、采集状态、最后成功时间和质量统计。
- 批次支持校验预览、接受/拒绝统计、重复提交幂等和失败原因下载。
- 验收：格式错误、来源未登记、批次重复和授权失效均有稳定状态与可审计结果。

### 2.4 规范化与特征质量门禁

- 维护来源模式到规范事件/流量字段的映射版本、单位和转换定义。
- 分别校验必填字段、类型、范围、时间戳、枚举、字段覆盖和来源可信度。
- 将记录分为可推理、待人工研判、拒绝三类；保存校验问题和映射版本。
- 验收：缺少模型必需字段或单位不匹配的记录不会被送入模型；修复映射后可重放批次。

### 2.5 模型注册、验证与推理路由

- 管理候选/已批准/已激活/已停用模型版本、制品位置、manifest、哈希、评估和运行时信息。
- 检查 manifest、权重哈希、特征顺序、预处理、标签、阈值、运行时与部署模式兼容性。
- 统一推理接口支持本机模型运行时和远端推理 API；保留模式、端点标识、模型版本和健康状态。
- 提供单条/批量推理、影子对比和健康检查；不同版本切换须显式审批并记录。
- 验收：校验失败模型不可激活；服务超时/版本不一致明确失败，不静默使用旧版本。

### 2.6 检测告警与事件研判

- 根据模型结果和确定性规则创建告警；记录输入摘要、数据质量、模型/阈值版本和证据引用。
- 按资产、时间窗、来源及关联标识将告警与安全/终端日志归并为事件。
- 展示事件状态、影响资产、证据时间线、关联告警、研判结论、处理人和处置历史。
- 支持确认、误报、升级、合并、拆分、分派和关闭；每次状态变化可追溯。
- 验收：告警能回溯到原始来源、特征映射和模型版本；重复输入不会产生无界重复事件。

### 2.7 风险评估与安全建议

- 以版本化、可解释规则综合模型分数、数据可信度、资产关键性、告警频度和独立证据数。
- 建议由批准的处置手册/模板生成，注明触发证据、适用条件、风险、时效和回滚方式。
- 首期趋势页只呈现已发生告警的历史统计；未来攻击预测为未实现的扩展能力。
- 验收：低质量/不完整数据不能被展示成高置信结论；用户可查看风险分级的组成项。

### 2.8 响应策略、审批与执行

- 策略按环境、资产范围、动作白名单、风险条件、时限、频率和审批要求匹配。
- 执行前复核授权状态和目标边界；默认拒绝未登记目标、任意命令、任意 URL 和参数注入。
- 支持策略内自动执行、人工审批、拒绝、撤销、执行超时和回滚；适配器凭据最小化隔离。
- 执行台账记录请求、策略快照、操作者、审批、适配器回执、状态和回滚句柄。
- 验收：越权请求 fail-closed；重试不重复执行；失败或过期动作有明确补偿/人工接管状态。

### 2.9 数据回放与隔离靶场

- 管理回放场景、文件/样本范围、运行速率、重复运行标识、当前进度和结果摘要。
- 支持暂停/继续/终止回放；将回放产生的事件标记为演练数据，与授权实网事件隔离展示。
- 靶场的外网隔离属于部署网络控制，不以 UI 选项代替；靶场动作仅调用靶场适配器。
- 验收：回放可重复；相同输入和模型版本可比较；运行不会向未授权目标发出流量。

### 2.10 报告、审计与运行健康

- 报告包含数据范围、模型/策略版本、告警与事件、处置和审计摘要，导出时执行脱敏。
- 审计覆盖登录、权限变更、数据接入、模型激活、策略编辑、审批、执行和回滚。
- 健康视图展示数据源、队列、推理端、模型版本、适配器和待办任务状态。
- 验收：审计记录不可由普通业务接口修改或删除；关键失败和积压能被发现。

## 3. 优先级与阶段交付

| 阶段 | 交付能力 | 退出条件 |
| --- | --- | --- |
| A：可验证基线 | 身份授权、资产/数据源、文件导入、质量门禁、模型注册/推理、告警事件、审计 | 公开数据端到端可复现，模型和输入可追溯 |
| B：安全响应闭环 | 回放、策略、审批、执行适配器、幂等、回滚、报告 | 隔离靶场全流程通过越权/重试/回滚测试 |
| C：授权实网试点 | 一种被动数据连接器、观察模式、领域差异和误报评估、小范围授权动作 | 数据映射及实测门槛通过书面评审，授权资产与动作可审计 |
| D：研究扩展 | 多事件时序预测或更多终端/安全日志解析 | 有合格标签、独立时间回测和明确误报成本后再立项 |

阶段 A/B 可以形成完整毕设闭环，但不能据此宣称模型已达到生产网络防护效果。阶段 C 是实际可用性的关键证据；其真实数据源与执行适配器须在实施前根据目标环境确定。

## 4. 不属于首期功能

原始包深度检测、终端代理/EDR、通用 SIEM/SOAR、未经验证的攻击预测、自由编排脚本、面向互联网的主动扫描或攻击生成均不纳入首期。
