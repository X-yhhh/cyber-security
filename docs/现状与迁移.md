## 4. 接入顺序

1. P3 完成数据准备、训练与冻结候选；P4 同步实现多分类推理、来源汇总和 v5 规则引擎；P5 实现 `peer_inbound` 并完成 Mac 必需场景。
2. P6 在 L1 test 上判定 G1/G2，报告 L2/L3。
3. P7 接入真实模型完成 G3 闭环。
4. P8 按资产授权启用已通过的类别；新路径失败时显式暂停并核对本机规则，旧 v4 路径不接管 v5 自动动作。
