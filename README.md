# 主机流量检测与受控自动阻断平台

本项目面向明确授权的 Mac/Windows 主机，通过自行训练的流量模型识别可观测攻击行为，经策略校验执行窄范围、限时、可撤销的本机防火墙阻断。模型必须对自动阻断产生可量化的贡献；不调用外部大模型 API，不训练大语言模型，不宣称全网可见或通用 DDoS 清洗能力。

交付范围按用户明确要求为**自用运行**：Windows离线训练，导出模型和必要配置到Mac，由现有后端或本地入口加载使用。不要求对外发行、独立安装包、代码签名证书或签名服务；正式发行签名不计入待完成项。程序须在目标机现有系统策略下实际可运行，模型须验证本机推理一致性；实际启用自动阻断时仍验证目标范围、到期与恢复。

## 技术与环境

- 应用仓库 `main`：JDK 25、Spring Boot 模块化单体、MyBatis、MySQL 8、RabbitMQ、Go 传感器。Redis 为可选优化，不是实施前提。
- 训练仓库 `training/windows-cuda`：Windows CUDA 离线数据处理、模型实验和 ONNX 导出，不合并训练资产到业务主干。
- 默认由 Mac 运行控制面，Mac/Windows 传感器只观测各自授权接口。控制面断开时不执行新阻断；本地恢复器仍负责已有临时规则到期清理。
- 原始 PCAP、端点账本、模型、训练输出、密钥、日志和备份不进 Git。配置与数据位于受控服务目录，仓库只保存实现、设计及小型去敏验收材料。
- 新方案允许检测入站与出站，按平台、协议、地址族、方向、攻击家族分别声明实测范围。首个自动动作候选为 IPv4/TCP 的对端服务级临时阻断；其他能力不得由解析成功推定。
