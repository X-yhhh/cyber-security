# 接口实现核对矩阵

本矩阵以 `backend/src/main/java` 当前控制器映射和权限注解为准，用于收口设计文档与实际代码的差异。`已实现` 表示路由、主要权限门禁和统一响应已存在；`部分实现` 表示路由存在但下游能力或运行态仍有明确边界；`未实现` 表示设计文档中的目标路由在当前代码中没有控制器映射。矩阵不把计划接口或测试替身当成实现。

## 稳定错误与验证要求

- 业务参数错误为 `400 INVALID_REQUEST`，未认证为 `401`，权限不足为 `403 FORBIDDEN`，范围外资源为 `404 NOT_FOUND`，状态/幂等冲突为 `409`，模型契约错误为 `422`，执行器不可用为 `503 ACTION_EXECUTION_UNAVAILABLE`。
- 所有响应使用统一 `ApiEnvelope` 和 request ID；日志通过 MDC 关联 `requestId`，不记录密码、令牌、Cookie、原始载荷或 SQL 详情。
- 设计文档中没有对应控制器映射的接口保持“未实现”，不得用前端页面、数据库表或内部端口推断为已开放 API。
