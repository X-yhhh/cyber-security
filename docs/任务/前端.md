### FE-9—FE-12 任务说明（rbac-v2，Q7）

排期见[开发路线第 2.1 节](../开发路线.md#21-初版-v10-落地当前主线)（初版 v1.0，Q9，不设日期）。**执行以[初版落地任务单](初版落地任务单.md)的 F0—F5、C1、T1 卡片为准**；以下为各任务的原始说明。初版要求 18 个二级页全部完成，不允许空页或占位页。

依据：[权限设计](../权限设计.md)第 7—9 节、[前端设计文档](../前端设计文档.md)第 4、7 节。

- **FE-9 权限导航基础**
  - 新建 `src/router/nav.ts`，作为唯一菜单配置：7 个一级组、18 个二级项，字段 `{group,key,title,en,path,anyOf,component}`；`router/index.ts` 由它生成控制台子路由。
  - `ConsoleLayout` 改为两级侧栏：一级可折叠，当前组默认展开，无可见二级项的组整组隐藏；顶栏面包屑显示“一级 / 二级 / 详情 ID”。
  - 路由守卫复用 `anyOf`：无权限时渲染 403 页，不挂载页面组件、不发请求；登录后默认进入 `/console/workbench`。
  - 验收：按权限设计第 7.3 节，对 6 个单角色会话做菜单快照测试（msw 模拟 `auth/me`），逐格一致；直达无权限地址显示 403 且 msw 无数据请求记录。
- **FE-10 v2 页面迁移**
  - 09—14 按前端设计文档第 4.2 节“去向”拆分：Release 拆成决策策略、能力与发布组合、评价与回放；Execution 拆成处置动作、目标预算（停用自动化按钮放在处置动作与能力与发布组合页头）；Health 拆成运行健康、审计日志。
  - 6 个旧 v2 地址重定向到新地址。
  - 验收：原 `DemoViews.test.ts` 等测试迁移后全部通过；页面语义和文案口径（“lab 自动（仅 lab）”“文件回放健康·不代表现场采集”等）不变。
- **FE-11 新建 v2 页面**
  - 只调用 `/api/v2`，写操作带 `Idempotency-Key`，审批类带 `If-Match`；按钮按权限设计第 8 节显隐。
  - 工作台卡片按第 7.4 节实现，计数写明“最近 N 条中”。
  - 事件研判包括列表、详情（timeline、状态迁移、追加记录、标注、发起处置申请）。处置申请只能引用判定绑定的稳定预算目标。
  - 系统管理两页等 BE-16 接口合入后再做。
  - 验收：每页四态（加载、空、错误、正常）、权限门控、至少一个写操作成功与 403/409 错误展示测试。
- **FE-12 删除 v1**
  - 删除 `OverviewView`、`EventsView`、`EventDetailView`、`ResponseView`、`ModelsView`、`AssetsView`、`SourcesView`、`SourcesShadowPanel`、`AuditView`、`IamView`、`DetectionRulesPanel`、`DetectionPoliciesPanel`、`AlertFeedbackDrawer` 及其测试。
  - 删除只服务 v1 的类型、`Pager`（确认无 v2 引用后）和 v1 接口封装。
  - BE-16 合入后，`session.ts`、`client.ts` 的 auth 与 CSRF 改为 `/api/v2/auth`，并去掉默认 `/api/v1` 前缀。
  - 验收：`grep -rn "/api/v1" frontend/src` 无结果（auth 切换前，只允许 auth 相关命中）；覆盖率仍满足阈值，不能通过降低阈值达标。
- **禁止事项**：不改后端、不改数据库；不把前端隐藏当作授权；不新增 v1 调用；不为凑覆盖率删除 v2 页面的现有测试。

## 2. 通用验收

- 锁文件安装、Vitest + msw 测试、覆盖率阈值、`vue-tsc` 与生产构建通过。
- 不信任前端传入的权限、风险等级或自动执行标志，所有校验在后端；写操作带幂等键与 `If-Match`。
- 机器侧路由（heartbeats、command-claims、observation-batches 上传等）不进控制台。
- 文案不得把计划能力写成已上线：未通过 G3 的类别显示为“只告警”，`replay_healthy` 显示为“文件回放健康（不代表现场采集）”。
