排期见[开发路线第 2.1 节](../开发路线.md#21-初版-v10-落地当前主线)（初版 v1.0，Q9，不设日期）。**执行以[初版落地任务单](https://github.com/X-yhhh/cyber-security/blob/v1.0/docs/任务/初版落地任务单.md)的 F0—F6、F0R、F1R、U0、C1、T1 卡片为准**；以下为各任务的原始说明，其中页面清单已被 Q10 的 6 组 12 项取代（[权限设计第 7.2 节](../权限设计.md#72-菜单清单)）。初版要求 12 个二级页全部完成，不允许空页或占位页。

### FE-16a 本人审批入口隐藏（门 0）

现状：`ActionsView.vue:158` 已按可选 `createdBy` 隐藏；`BundleDrawer`、`PolicyDrawer`、`LabDrawer` 尚无对应判断。
1. BE-25 合入后，在 `api/types.ts` 给动作、组合、策略、lab 会话补可选字段（`createdBy` / `requestedBy`，`number | string | null`），与 `api/v2/assets.ts` 的 `requestedBy` 写法一致。
2. 四处统一用一个小工具判断“是否本人”：字段为 null 或缺省时视为未知，按钮照常显示，由后端拦截；**只按数字 ID** 与 `session.user.id` 比较（不比 username），相等时隐藏批准、驳回、激活，并显示“本人发起，需他人审批”。可复用 `AssetDetailView.vue:256` 的 `mine/maybeMine` 逻辑，抽到 `composables/` 后两处共用。
3. MSW 夹具给对应行补字段（一行本人、一行他人、一行 null）。
4. 测试：每个页面三种情况各一条断言（并入 FE-16b/c/d 的测试文件）。

验收：typecheck、相关测试通过；浏览器用两个账户各看一次（本地 5173 指向隔离后端或 MSW 均可）。
禁止：前端自行拦截提交——按钮隐藏只是展示，后端 `APPROVAL_SEPARATION_REQUIRED` 仍是唯一强制点。

### FE-17 演示观看路径（门 3，录屏前）

目的：C2 录屏时，评委能在控制台按顺序看到“实时态势曲线 → 事件 → 证据组里的 inbound 规则来源”。现状：实时态势**不支持按资产筛选**（`stats/live` 只接受 `range`、`step`，按调用者权限范围内全部资产聚合），所以演示期间 en0 的日常流量会混进曲线。
1. 先做选择：
   - (a) 录屏用一个只绑定 lab 资产 `tailscale-demo` 的账户登录（资产范围角色），曲线自然只包含演示资产。不改代码，但**新建账户和绑定要写业务库**，需要单独授权；资产范围绑定要填资产的**内部编号**，目前前端没有映射接口（FE-18 的缺口），只能在 B8 之后用只读 SQL 查出 `tailscale-demo` 的内部 ID，再手填。推荐此方案。
   - (b) 给 `stats/live` 加 `assetId` 参数：属于后端改动并需要新测试，归后端方向，单独开卡。
2. 选 (a)：B8 之后建 `demo-viewer` 账户，只授予 lab 资产范围的 `security_analyst`（或只读角色），记录到演示方案第 12 节。用它把实时态势、事件研判（按资产与时间筛选）、事件详情证据组的“来源”列走一遍，确认 `ruleId` 与 `inbound` 都能看到。
3. 输出一份录屏脚本（页面顺序、每页停留秒数、要指给评委看的字段），写进演示方案第 9 节“答辩现场流程”。

验收：用 C1 彩排产生的真实数据走一遍，截图存证；不新增页面或权限键。

### FE-18 角色绑定的资产选择器（可选）

现状：用户绑定资产范围时只能手填资产**内部十进制 ID**（`scopeId`），而资产列表只给公开 UUID，两者没有映射接口（`views/system/shared.ts` 已注明）。
1. 先定契约（后端方向）：二选一——资产读视图增加只读 `scopeId`（内部 ID）给 `iam.manage` 用户，或绑定接口改为接受资产公开 UUID 再由后端换算。写进权限设计与接口设计后再动前端。
2. 前端改为下拉选择资产（显示 assetKey + 显示名），提交时按契约传值；保留手填作为回退。
3. 测试并入 FE-16b。

## 2. 通用验收

- 锁文件安装、Vitest + msw 测试、覆盖率阈值、`vue-tsc` 与生产构建通过。
- 不信任前端传入的权限、风险等级或自动执行标志，所有校验在后端；写操作带幂等键与 `If-Match`。
- 机器侧路由（heartbeats、command-claims、observation-batches 上传等）不进控制台。
- 文案不得把计划能力写成已上线：未通过 G3 的类别显示为“只告警”，`replay_healthy` 显示为“文件回放健康（不代表现场采集）”。
