# P1 可观测性矩阵

对应[机器可读矩阵](coverage-matrix.json)和[标签策略](label-policy.md)。采集点均为发布者以太网 PCAP 中的 IoT 本机锚点；不是当前 Mac/Windows 实时抓包。所有包均完整离线读取，三个文件未观察到时间回退；历史内核丢包统计未知，不能报告零丢包。

| 特征或证据 | TCP | UDP | 标签起点与限制 |
|---|---|---|---|
| IP 总长度、双向 bytes/packets | 头部参考可计算，拒绝长度回填和必要头部缺陷 | 同左 | 以本机发送/接收定义双向，不以 Zeek orig/resp 替代 |
| length min/max/mean/std | 已对样本计算 | 已对样本计算 | std 为总体标准差，单包为 0；超过 1500B 非分片单列卸载嫌疑 |
| IAT mean/std | 已对样本计算，单包 null | 同左 | 参考按时间/原序号排序；不能作为 P2 在线乱序证明 |
| SYN/SYN-ACK/RST/FIN/握手 | 已对样本计算顺序握手 | null | 只读捕获点可见标志，不推断缺失握手 |
| direction/对端/服务 | 首个关联包为纯 SYN 时可确定；无 SYN 为 unknown | 不授予执行方向或目标 | 可构造元数据不等于现场有授权/租约的 targetRef |
| elapsed/prefix/final | 可用捕获时钟研究 1s/5s 截止点 | 同左 | 当前是参考统计，攻击起点没有真值，全部 final_only |
| 1/5/30s peer/host 上下文 | 原始时间和头部具备计算来源 | 同左 | P2 引擎、水位、coverage、gap、parentConnection 尚未实现 |
| quality/真实健康 | 已审查解析、长度、锚点、关联和时间回退 | 同左 | historical drops=null；现场卸载/丢包/Npcap 未对拍 |
| ICMP、IPv6、其他链路 | 本次不授予支持 | 本次不授予支持 | ICMP type/code 与端口关联不同，必须单独实现，不以 UDP 默认值替代 |

## 家族与独立活动

| 发布者家族 | 已取得的独立捕获 | P1 结论 | 下一项验证 |
|---|---|---|---|
| 水平扫描 | 3-1、34-1 | 正例头部与目标服务可观察；跨 peer 扫描窄规则覆盖未证明，仅告警研究 | 逐目标作用范围裁决，不能扩成全端口或整机封禁 |
| DDoS | 34-1 | 12 条抽查歧义，零包计数与捕获矛盾；不授予 sustained_flood 数据出口 | 重建连接 epoch、修订可追溯标签，补独立攻击活动/起点 |
| C&C | 8-1、3-1、34-1 | 不同捕获活动存在；完整连接研究可开展，尚无检测收益或 prefix 标签证据 | 合法定时服务、重试、下载等困难负例；不得直接改名为已支持家族 |
| 良性 | 各恶意捕获内均有 publisher Benign | 来源内正负对照存在，未把来源身份等同标签 | 补桌面授权任务；IoT 良性不能代表 Mac/Windows 全部业务 |

现有原件无需增加到全量 IoT-23 压缩包；首轮开发预算保持最多两个来源、每来源 100,000 parentConnection。当前没有 parentConnection 全量构建或 final_test 分配，不能把 189,651 条发布者连接数等同可用于训练的独立样本。
