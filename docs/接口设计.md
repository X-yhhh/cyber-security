# 接口设计

## 1. 约定

- 基础路径 `/api/v1`，JSON UTF-8，时间使用 ISO-8601 UTC；前端不直接访问 MySQL、Redis 或 RabbitMQ。
- 用户接口使用认证会话；连接器使用独立客户端身份。所有资源访问按角色和资产/数据源范围二次授权。
- 每个请求支持/返回 `X-Request-Id`；可重试写请求使用 `Idempotency-Key`。异步操作返回 `202 Accepted` 和任务 ID。
- 统一错误结构：`code`、`message`、`requestId`、`details`。不得在错误中泄露密钥、内部堆栈或敏感载荷。
- 分页采用 `page`、`size`，限制最大页长；列表过滤和排序字段采用服务端白名单。
- 所有时间、分数和模型概率的语义在响应中明确；未经校准的输出标为 `score`，不标为概率。

## 2. 统一响应

成功响应：

```json
{
  "data": {},
  "meta": {
    "requestId": "req_01...",
    "timestamp": "2026-09-23T01:00:00Z"
  }
}
```

错误响应：

```json
{
  "error": {
    "code": "MODEL_CONTRACT_MISMATCH",
    "message": "输入数据不满足活动模型的特征契约",
    "requestId": "req_01...",
    "details": [{"field": "duration", "reason": "unit_mismatch"}]
  }
}
```

主要状态码：`400` 参数错误，`401` 未认证，`403` 无权限/超范围，`404` 不存在，`409` 幂等冲突/状态冲突，`422` 数据或模型契约不满足，`429` 限流，`503` 推理端/队列/适配器不可用。

## 3. API 清单

| 域 | 方法与路径 | 用途 |
| --- | --- | --- |
| 传感器 | `POST /sensors/register`, `POST /sensors/{id}/heartbeat`, `GET /sensors/{id}/config` | 传感器注册、心跳、拉取授权采集配置 |
| 传感器遥测 | `POST /sensors/{id}/flows`, `POST /sensors/{id}/health-windows` | 上传规范化流记录/告警摘要和健康统计；不接收逐包消息总线 |
| 会话 | `POST /auth/login`, `POST /auth/logout`, `GET /auth/me` | 登录、退出和当前权限摘要 |
| 用户/角色 | `GET/POST /users`, `GET/POST /roles`, `PUT /users/{id}/roles` | 管理用户、角色及范围授权 |
| 资产 | `GET/POST /assets`, `GET/PUT /assets/{id}`, `POST /assets/{id}/authorizations` | 登记资产、关键性和授权有效期 |
| 数据源 | `GET/POST /data-sources`, `GET/PUT /data-sources/{id}`, `POST /data-sources/{id}/mappings` | 数据源及字段映射版本 |
| 导入 | `POST /ingest/batches`, `GET /ingest/batches/{id}`, `GET /ingest/batches/{id}/errors` | 提交批次、查询状态和错误 |
| 模型 | `GET /models`, `POST /models`, `POST /models/{id}/validate`, `POST /models/{id}/approve` | 登记、校验和审批模型制品 |
| 推理路由 | `GET /model-deployments`, `PUT /model-deployments/active` | 查看/切换本机或远端活动部署 |
| 推理 | `POST /inference`, `POST /inference/batch`, `GET /inference/{id}` | 单条/批量预测及异步状态 |
| 检测规则 | `GET/POST /detection-rules`, `POST /detection-rules/{id}/approve` | 管理确定性方向、服务和速率规则 |
| 漂移监测 | `GET /drift/windows`, `GET /drift/alerts`, `POST /drift/alerts/{id}/acknowledge` | 查询时间窗分布统计和漂移告警；不触发在线训练 |
| 人工反馈 | `POST /feedback-samples`, `GET /feedback-samples` | 分析员提交有依据标签，管理训练资格 |
| 离线再训练 | `POST /model-training-jobs`, `GET /model-training-jobs/{id}`, `POST /model-training-jobs/{id}/approve` | 创建/审批 Windows 离线训练候选任务 |
| 模型发布 | `POST /models/{id}/shadow`, `POST /models/{id}/release`, `POST /models/{id}/rollback` | 影子验证、人工批准发布和回退 |
| 告警事件 | `GET /alerts`, `GET /events`, `GET /events/{id}`, `POST /events/{id}/transitions`, `POST /events/{id}/notes` | 筛选告警、查看证据时间线、研判和状态迁移 |
| 策略响应 | `GET/POST /response-policies`, `POST /events/{id}/actions`, `GET /actions/{id}` | 管理版本化策略、提交动作候选和查询执行状态 |
| 审批 | `GET /approvals`, `POST /approvals/{id}/decision` | 审批或拒绝待处理动作 |
| 回放 | `GET/POST /replay-scenarios`, `POST /replay-runs`, `POST /replay-runs/{id}/control` | 创建场景、启动/暂停/继续/终止回放 |
| 审计/报告 | `GET /audit-logs`, `POST /reports`, `GET /reports/{id}` | 查询授权审计和异步导出 |
| 健康 | `GET /health/live`, `GET /health/ready`, `GET /ops/status` | 存活、依赖就绪和受权限保护的运行状态 |

`PUT /model-deployments/active`、审批、策略发布和响应执行属于敏感操作，应要求专门权限并生成审计事件。
传感器 API 使用独立机器身份和资产范围授权；心跳或流记录接口不能调用策略、审批或防火墙动作。传感器只能上报流级记录、命中摘要、质量/健康信息，不上传原始载荷，除非另有明确设计、授权和留存审查。

## 4. 传感器与在线检测契约

传感器注册请求绑定 `agentKey`、`assetKey`、平台/版本和能力摘要；资产授权校验通过后才签发短期设备身份。传感器到控制面的连接使用 TLS 和独立机器身份；注册凭据需轮换/撤销，传感器 API 按 agent 到 asset 的绑定授权，不能复用用户会话凭据。配置响应包含配置版本、批准接口/过滤范围、流超时/窗口、`featureContractVersion`、模型版本引用、上报目的地及配置过期时间。配置不得包含可自由执行的命令或凭据明文。

流量上报采用有界批次，包含 `sensorId`、`configVersion`、`sequence`、`observedAt`、`featureContractVersion` 和流记录数组。服务按传感器身份核对绑定资产、序号/幂等键、时间偏差、字段覆盖和授权来源。支持重复安全重试；拒绝记录字段级错误。过载由传感器上报 `flowsSeen/emitted/dropped/queueDepth`，不能只上报已成功检测数据而隐藏丢弃。

传感器离线时，控制面显示覆盖降级。设备可在有效的签名配置期限内继续既有本机检测/已批准规则，但不得接受过期动作或自行更改模型。恢复连接后补报摘要时仍进行幂等和时间范围校验。

## 5. 关键接口契约

### 5.1 批次导入

`POST /api/v1/ingest/batches`，请求头含 `Idempotency-Key`。请求体包含 `dataSourceKey`、`schemaVersion`、`records` 或受控文件引用；大文件不内嵌单个 JSON 请求。

记录至少携带 `sourceRecordKey`、`eventType`、`eventTime`、可选 `assetKey` 和 `payload`。服务先校验来源授权，再返回 `202`：`batchId`、`status`、`receivedCount`。完成后批次包含接受/拒绝数及字段级错误。重复幂等键返回既有批次状态，不重复建任务。

### 5.2 推理

`POST /api/v1/inference` 请求引用一个已接入记录，或提交符合模型契约的规范化流记录，并指定 `inputContractVersion`。调用方不得指定未激活的任意模型；影子对比需单独权限和显式模型列表。

```json
{
  "inputContractVersion": "unsw-flow-v1",
  "records": [{
    "recordKey": "flow_01...",
    "features": {"dur": 0.42, "proto": "tcp"}
  }]
}
```

响应可能为同步结果或 `202` 任务引用。每个结果含：`recordKey`、`status`、`modelKey`、`modelVersion`、`deploymentMode`、`binaryLabel`、可选 `attackCategory`、`score` 或经校准的 `probabilities`、`thresholdPolicyVersion`、`qualityStatus`、`latencyMs`、`createdAt`。字段不全/单位或版本不符返回 `422 MODEL_CONTRACT_MISMATCH`，不对该记录静默推理。

### 5.3 模型校验与激活

模型登记使用受控 `artifactRef`，不通过浏览器上传任意可执行文件。校验端点检查哈希、manifest、标签/特征契约、运行时支持和冒烟推理，返回逐项检查结果及状态。只有 `validated` 且审批通过的版本可激活。

激活请求明确 `mode` (`local` 或 `remote`)、`modelVersionId` 及部署引用。远端凭据通过服务端密钥引用解析，绝不出现在请求/响应。模式切换记录操作者、原因、旧新版本和健康检查结果；检查失败保持原状态并返回错误，不隐式回退。

### 5.4 创建响应动作

分析员/策略流程提交 `eventId`、`assetId`、白名单 `actionType`、有限参数、`reason` 和 `Idempotency-Key`。服务端返回动作状态 `rejected|pending_approval|queued`。

请求中的目标必须已登记、授权有效且属于策略范围；客户端不能提交 shell 命令或任意 URL。动作参数只能表达窄范围、带 TTL 的阻断，不允许覆盖主机默认防火墙策略；服务端校验保护资产和管理连接。风险等级、自动执行与审批由服务端策略决定，不能由调用者用参数绕过。超范围或授权过期返回 `403`，策略冲突返回 `409`，并产生审计记录。

### 5.5 审批与回滚

审批请求包含 `decision` (`approve`/`reject`) 和理由；审批人不能是策略禁止的发起者。审批只授权具体动作快照，不授予后续任意操作。动作状态端点提供适配器结果和回滚能力标志；回滚使用专用 `POST /actions/{id}/rollback`，再次进行范围和权限校验，返回异步状态。

## 6. 数据源/推理/响应适配器内部端口

以下是服务内部契约，不直接暴露为任意远程管理 API：

- `FlowNormalizer`: 来源记录 + mapping version → 规范记录 + 质量问题。
- `InferencePort`: 模型版本 + 合格规范特征 → 版本明确的分类结果或可分类错误。
- `ResponseExecutor`: 策略签名的动作 + 授权资产快照 + 幂等键 → 主机防火墙执行回执/到期或回滚引用。
- `SensorConfigPort`: 传感器身份 + 当前授权 → 最小权限签名配置；不得返回任意命令。

每种实现需要健康检查、超时、限流、错误分类和审计字段。响应实现只能由管理员配置的适配器注册，不允许用户动态指定类、脚本或任意 endpoint。

## 7. 漂移、反馈与离线训练契约

- 漂移接口只读取固定时间窗统计及状态，不提供任何更新活动权重的 API。
- 反馈样本必须引用原始流/告警、人工标签、标签依据、审核人和时间。系统不得将模型预测自动复制为真实标签。
- 创建离线训练任务需指定经批准的数据集版本、标签清单、算法候选和 Windows 训练环境。任务运行在训练环境，与在线传感器推理隔离。
- 训练任务完成只登记候选制品和评估报告；候选须通过哈希/manifest、锁定测试、类别召回/正常误报、特征兼容、推理性能和影子观察，再由有权限人员发布。
- 发布接口需记录旧/新模型版本、批准人、部署目标、校验结果和回退版本；任何门禁失败都保持现有活动版本。
- 本项目不提供大语言模型训练/微调或在线自学习接口。
- 限速动作只有在目标平台适配器能力清单和运行时健康检查均确认支持后才允许提交；不支持时 API 返回 `ACTION_NOT_SUPPORTED`，不得降级成语义不同的阻断。

## 8. 异步任务和安全控制

- 导入、批量推理、回放、处置、报告均有可查询任务 ID、状态、进度、失败原因和重试策略。
- 消费者按任务 ID/幂等键去重。响应动作重试前检查既有执行记录和适配器回执，不可盲目重放。
- 任务取消只在其状态和动作语义允许时成功；正在执行的外部动作须通过适配器补偿/撤销，不能仅更新数据库状态。
- API 访问按用户/客户端、资产范围、环境和动作类型授权；写入审计及请求关联 ID。外部错误消息脱敏。
- OpenAPI 文件应在实现阶段由本设计生成并纳入契约测试；当前文档定义语义，不代表接口已实现。
