# 网络威胁检测与受控防御平台 - 前端系统 (SecOps Console)

本项目基于 **Vue 3 稳定版 + Vite 6 + TypeScript + Tailwind CSS** 构建，采用现代化**高保真浅色科技防务风 (Clean Modern Light Cyber-SecOps Theme)** 设计。界面高级、审美统一、布局严谨，各功能模块严格对齐系统的设计契约（《项目详细设计》、《功能模块设计》、《接口设计》、《数据库设计》）。

---

## 1. 核心设计风格规范 (浅色科技主题)

- **底色与表面**：页面主底色为纯净冷灰 `#f8fafc` (Slate 50)，卡片采用纯白 `#ffffff`，辅以 1px 细微边界 `#e2e8f0` 与柔和多层微投影；
- **品牌科技蓝**：主色调选用科技钛青与深钴蓝 `#0284c7` (Sky 600)；
- **安全语义色彩**：
  - **危急 (Critical)**: 背景 `#fef2f2`，边框 `#fecaca`，文字 `#dc2626`
  - **高危 (High)**: 背景 `#fff7ed`，边框 `#fed7aa`，文字 `#ea580c`
  - **中危 (Medium)**: 背景 `#fefce8`，边框 `#fef08a`，文字 `#ca8a04`
  - **低危 (Low)**: 背景 `#f0fdfa`，边框 `#99f6e4`，文字 `#0d9488`
  - **安全 (Safe)**: 背景 `#f0fdf4`，边框 `#bbf7d0`，文字 `#16a34a`
  - **待办 (Pending)**: 背景 `#faf5ff`，边框 `#e9d5ff`，文字 `#9333ea`
- **专业数据排版**：IP 地址、端口、MAC、五元组、哈希、TTL 与特征契约统一采用等宽字体 (`JetBrains Mono`, `Fira Code`) 排版。

## 3. 7 角色快速切换模拟器 (无需后端体验)

在顶栏右上角内置了 **“角色模拟切换器”**，可随时一键切换为 7 大内置角色体验不同的操作权限与界面边界：
1. **平台管理员 (platform_admin)**：全局管理与资产审批、全局只读查看审计；
2. **安全分析员 (security_analyst)**：事件研判、追加分析笔记、发起受控阻断申请；
3. **响应审批员 (response_approver)**：审核并裁决阻断工单（申请人不可自我审批）；
4. **模型操作员 (model_operator)**：登记候选模型、发起模型发布审查；
5. **模型发布审批员 (model_releaser)**：独立审查模型 Manifest 并批准发布；
6. **资产管理员 (asset_source_admin)**：资产与数据源维护；
7. **合规审计员 (auditor)**：合规审计日志查看与报告导出。

```bash
# 预览生产构建结果
npm run preview
```

## 5. 后续无缝对接后端方式

系统内置了契约完全对齐的 API 客户端（`src/api/client.ts`），严格遵循后端 `ApiEnvelope`（`{ success, data, error, requestId }`）结构。
当 Spring Boot 后端服务启动于 `127.0.0.1:18080` 时，只需在 `src/api/client.ts` 中设置：
```typescript
export const IS_MOCK_MODE = false;
```
前端所有请求将通过 Vite Proxy 自动转发到 `http://127.0.0.1:18080/api/v1`，携带 CSRF Token、Session Cookie 与 `X-Request-Id`，实现零成本无缝平滑对接。
