# 主机流量检测与受控自动阻断平台

面向明确授权的 Mac/Windows 主机，以自行训练的流量模型识别可观测行为，经策略校验执行窄范围、限时、可撤销的本机防火墙阻断。模型必须相对仅规则提供可量化收益。系统不依赖外部大模型 API，不训练大语言模型，不宣称全网覆盖或通用 DDoS 清洗能力。

## 实施与交付边界

- `main` 承载本机应用、接口及设计；`training/windows-cuda` 承载 Windows 离线训练和导出。P3 使用 prefix 入口，具体兼容条件见其执行文档。
- 技术基线为 JDK 25、Spring Boot 模块化单体、MyBatis、MySQL 8、RabbitMQ、Go 传感器；Redis 是可选优化。
- 自用交付由 Windows 导出 ONNX 及配置到 Mac 的本地推理入口。无需独立安装包、程序发行证书或持续入站影子运行；内部命令鉴权和完整性核验仍必须完成。
- P4/P5 可以基于已收口的 P1/P2 分别开发，P7 汇合 P4、对应平台 P5 和 P6。前端由用户后续自行处理，不列入阶段门槛。
- 原始 PCAP、端点账本、模型、运行结果、密钥和备份保存在受控目录，不进 Git。docs 保存当前规范与计划，不继续堆叠阶段生成报告。
- 真实采集、训练、数据库变更、部署和动作执行依照各次明确授权实施；文档更新本身不启动这些操作。
