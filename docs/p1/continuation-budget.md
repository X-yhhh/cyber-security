# P1 定向补证预算决策

日期：2026-10-03。用户已授权完成阶段 1、自行决策和下载，并在官方入口完成登记。

原 2 GiB 预算无法容纳 CICIDS2017 的一个完整工作日 PCAP。IoT-23 的既有抽查仍存在计数矛盾、连接 epoch 和 prefix 起点缺口；继续增加相同类型小捕获不能直接解决 HTTP 服务入站窄规则任务的可行性问题。

本轮将原件总预算上调至 **32 GiB**，只下载官方 Wednesday-workingHours 和 Friday-WorkingHours 两个完整 PCAP、官方 MD5 及对应研究修正表。官方标称分别约 13G、8.3G；保留 SHA-256、下载来源和许可/引用。预计收益是取得多个有公开时段记录的服务滥用活动、同源良性背景和可核对的原始报文。先校验完整容器和标签，再决定任务；不能因为下载成功就宣称早期自动能力通过。

官方下载较慢，增加同一 PCAP 的 Kaggle 镜像分段续传。周三使用已取得的官方 MD5；周五先核对镜像 MD5，独立官方校验另行登记，不能混称。每文件最多 16 个 64 MiB 分段并发，失败段有界重试，已有完成账本可续传。镜像不增加研究来源；尚未完整校验的文件一直保留 `.partial` 状态。为容纳官方传输与镜像暂存重叠，派生索引/临时副本另限 **32 GiB**，校验完成后只归档本任务所需原件。下载前本机剩余空间约 489 GiB。

排除全周、其他来源、模型训练及 final_test 分配/评估。已探索活动一律视为开发暴露，后续独立评估活动须另行冻结。若文件超过预算、许可不允许或关联失败，记录原因并停止该扩展，不静默继续扩大。

原始数据与包含地址的关联账本仅保存在 Git 忽略目录；登记信息不复制进证据或代码。
