# 主机流量检测与受控自动阻断平台

面向明确授权的 Mac/Windows 主机：传感器持续采集入站流量并提取特征，自行训练的多分类模型识别端口扫描、暴力破解、洪泛 DoS 和慢速 DoS，后端按来源汇总证据后，由独立执行器实施窄范围、限时、可撤销的本机防火墙封禁。规则引擎并行作为第二条检测来源。系统不依赖外部大模型 API，不训练大语言模型，不宣称全网覆盖或通用 DDoS 清洗能力。

## 实施与交付边界

- 远端长期分支只有 `main`（本机应用、接口及设计）与 `training/windows-cuda`（Windows 离线训练和导出，多分类训练入口在 `src/cyber_training/host_guard/`）；临时分支经 PR 以 merge commit 合并后删除。
- 技术基线为 JDK 25、Spring Boot 模块化单体、MyBatis、MySQL 8、RabbitMQ、Go 传感器；Redis 是可选优化。
- Flyway 是唯一结构来源，新库由 Flyway 从空库迁移到最新（代码与业务库当前均为 V27）；旧初始化脚本已退役。本机管理员由 `LocalAdminBootstrap` 在显式 local profile 下引导，已有 admin 行与口令哈希保持不变。
- 自用交付由 Windows 导出 ONNX 及配置到 Mac 的本地推理入口。无需独立安装包、程序发行证书或持续入站影子运行；内部命令鉴权和完整性核验仍必须完成。
- P7 汇合 P4、Mac 平台 P5 和 P6，已于 2026-10-13 通过 G3；2026-10-14 P0 与部署准备收尾完成；P8 已进行后端分段部署，完整接入仍待授权；真实主机只告警（Q3）。前端不列入阶段门槛，演示最小集已纳入（A9）。
- 原始 PCAP、端点账本、模型、运行结果、密钥和备份保存在受控目录，不进 Git。docs 只保存当前规范、计划与精简执行记录，不堆叠阶段生成报告或临时任务单。
- 真实采集、训练、数据库变更、部署和动作执行依照各次明确授权实施；文档更新本身不启动这些操作。
