# P1 定向任务的可观测性与后续实现边界

本表针对 IPv4/TCP/单个 HTTP 服务入站连接滥用。参考契约为 `host-guard/5.0.0-rc.1`；它说明数据是否支持继续实现，不授予模型或执行器自动资格。逐条关联和起点结果见[数据审计](continuation-data.json)，阶段结论见[补证报告](continuation-report.md)。历史 IoT-23 矩阵继续保留，不覆盖其失败。

| 特征或证据 | 来源与计算方式 | 缺失、质量与实施边界 |
|---|---|---|
| 双向 IP bytes/packets | 以被保护服务为本机锚点，从截止点前的 IPv4 长度及方向计算 | 不把 TCP 载荷量当 IP 字节量；不按 MSS 重建包数 |
| 包长 min/max/mean/std | 可见双向 IP 包的头部长度，标准差为总体标准差 | 单包 std=0；卸载大包单列，不能进入自动候选 |
| IAT mean/std | 截止点前相邻包的微秒时间间隔 | 单包为 null；乱序参考统计显式不可用，P2 必须实现同一有界乱序规则 |
| SYN/SYN-ACK/RST/FIN | 只读 TCP 标志；SYN 与 SYN-ACK 分开计数 | 2026-10-04 修正 Python 参考实现重复计入 SYN-ACK 的问题；旧正常任务审计保留，新版另存 |
| handshakeSeen | 同一关联窗口内按序核验 SYN、SYN-ACK、ACK 及确认号 | 无起始 SYN、多个 epoch 或关联歧义不能构造自动目标证据 |
| direction/serviceClass/目标元数据 | 起始纯 SYN 确定发起端，以服务端为本机锚点；服务端口作元数据 | 公开 PCAP 不能生成现场有效 targetRef、资产授权或租约；研究结果不执行动作 |
| elapsed/prefix | 根据捕获时间可构造 1s、5s 及随后每 5s 截止点 | 当前仅为有界参考；流结束、120s 续段、快照调度和 parentConnection 由 P2 实现 |
| 攻击起点 | 发布者非 Attempted 标签 + 完整连接关联 + 有界载荷旁路审查 | 普通 GET、最终攻击标签或攻击时段都不能单独批准起点；起点前为 Unknown |
| 1/5/30s peer/host 上下文 | 包时间、方向、IP 长度、连接发起和服务元数据提供计算来源 | 尚未实现水位、coverage/gap、窗口边界和跨段去重；不能宣称全部 43 个数值字段已经对拍 |
| capture quality | 完整容器、长度、分片、卸载、时间回退及关联异常分别审计 | PCAP 完整不证明发布者历史内核零丢包；原始数据与现场采集点仍须 P2 对拍 |
| Windows 正常任务 | 下载、四路并发、中断及 Range 恢复，按固定夹具和受控任务赋标签 | 9 个五元组、2,958 帧；1 项合法任务超时保留，不能代表实网误伤率 |

## 独立活动和预算

两个 CICIDS2017 工作日的全部已探索活动均为开发暴露，不分配 final_test。CSE-CIC-IDS2018 的 2018-02-15 Slowloris/GoldenEye 活动仅完成官方说明、修正说明及公共对象元数据核查；约 41.28 GB 原始归档尚未下载、未审包、未验证 SHA-256。它提供后续独立活动可获取性的线索，不是已冻结或已通过的最终测试集。

当前原件预算保持[已批准的 32 GiB](continuation-budget.md)，不追加全周或第三来源的原始数据。P2 首轮最多处理 100,000 个 parentConnection；先按源捕获、目标主机、活动、TCP epoch 和重复组建立索引，再限制规模。不得直接把表格行数或 120s 分段数当独立连接数。后续读取新的独立评估原件前须先冻结评估计划、用途、预算及暴露登记。

## 平台边界

Windows 窄规则与独立清理仅证明有界可行性；严格跨重启 TTL 超时必须保留。P5 需实现可信时钟、持久账本和接受新命令前的清理门禁，P7 再进行完整联合验收。Mac 当前为 `blocked_missing_isolated_asset_scope`，仅只读预检，不支持自动动作；IPv6、UDP、出站动作和限速均未获资格。本轮不再安排重启，不改变现有 v4 运行时。
