## 2. 长期正常任务的真实证据

本轮用户明确授权 `win-dev` 的 Npcap 回环接口，仅 `127.0.0.1 ↔ 127.0.0.2`、IPv4/TCP/80、最多四路并发，八批分两个≤30分钟窗口。窗口实际为 **1,223.783 秒、1,068.432 秒**，批间至少155秒；每批另建引擎/boot/capture，资产和稳定目标预算身份保持一致。TCP/80 使用 Windows 独占绑定，已有监听时拒绝执行。

| 名义下载连接 | PCAP 实际最短 | PCAP 实际最长 |
|---|---:|---:|
| 30秒 | 29.997034秒 | 30.023441秒 |
| 60秒 | 60.000868秒 | 60.025507秒 |
| 120秒 | 120.003963秒 | 120.018536秒 |

第七批30秒连接比名义时长短2.966ms，真实值不取整。实测该 Python 3.12 的 `time.monotonic()` 使用 `GetTickCount64()`、分辨率15.625ms；验收仅对名义业务时长使用这一登记误差，不改变证据新鲜度、动作截止或模型时延门槛。响应内容、长度与哈希均核验成功；最大实际并发4。任务结束后的 PowerShell 监听检查和独立 `netstat` 均未发现 TCP/80 监听。

八批产生407条质量合格的候选良性 prefix；offload 可疑观察未加入。按去端点、10ms相对时序、方向/flags/IP/载荷长度审查，发现6组跨活动重复，5组跨角色。29个重复parent整体排除，移除55条prefix，保留352条：计划训练44、选型44、校准44、独立开发220。角色名称是原任务登记，**不表示已经完成正式分区或获得五个独立网络域**；相同主机/确定性任务及其他近重复依赖仍须在冻结时处理。

采集由原有获准 Python/Npcap 绑定完成，保存原生 DLT_NULL，没有生成去 AF 头的替代特征输入。Go 直接读取原件，业务重组只用于私有标签旁路。此证据不能替代 Go cgo live 的同句柄实际验收，也不能外推物理接口或 Mac。

## 3. 早期标签、来源和时间线

CIC2018 审查7,247条唯一已匹配SYN epoch，725条具有来源限定的慢头续传证据，6,522条Unknown；其中2,232条Attempted不作为正例。新构建得到1,927条攻击prefix、487个parent。保留725个连接标签时间段，其中238个没有合格观察。**同一目标重叠连接归并后只有1个攻击区间、1个独立活动**，不能把连接数当活动或最终100个episode。

新 builder 分开连接时间线与目标时间线；无观察段、起点前/等于证据时刻、发布窗口外和不可证明的后续质量均显式保留或排除，Unknown不转正常。原件、标签、审查、观察和账本重新核对SHA-256。新材料为开发待分区版本，`trainingAllowed=false`，旧final研究集/冻结清单不变。

CIC2017全量4,215条保持Unknown。在1,406条正例完整关联中，1,027条出现零窗口，但没有一条出现多次零窗口；仅194条可连续重组完整首请求。响应/窗口诊断保留，不能仅凭一次零窗口判断慢读取攻击，也不能把慢头规则套在该来源。

TAARA/Rios共19个PCAP已解压。final角色在模型载荷分析前预留；与final相邻不足150秒的捕获整体封存。开发材料谱系审查为7个关联组、5个来源日聚类，但这只是容器/谱系数量。TAARA以论文表II/V登记的攻击端、正常host和服务范围为依据，再与完整SYN epoch、因果HTTP状态及Apache请求唯一关联；Suricata告警不参与标签。日志无源端口，同秒相同请求的歧义全部Unknown，结果292条攻击、1条正常、11,389条Unknown，合格攻击只覆盖2个关联组/1个来源日。Rios混合流量尚未完成逐连接真值关联。

三个已登记尾损保留原件，派生件只截到完整记录边界并排除尾部150秒上下文/跨界parent；TAARA Ringan3移除54字节、Rios emulated移除11字节、lan移除750字节。final仅作完整性派生，不读取模型特征/分数。封存预留尚不等于完成P6正式分区。

## 4. 策略与交付边界

`target-budget-v2`必须有稳定真实目标旁路；缺失拒绝候选动作。六轮30秒租约即使间隔2ms也只能批准四轮，累计最多120秒。只有完整120秒捕获健康、无有效攻击证据的冷却可重开额度；健康状态不能从单条低分观察推断。非有限时刻、非法租约拒绝。历史复算显式使用 `legacy-final-diagnostic-v1`，旧19/28、4/28、81/84不改写。
