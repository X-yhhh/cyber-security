# 功能模块设计

## 1. 角色与权限矩阵

角色只授予功能权限，资源范围另行限制到明确资产、数据源或模型注册范围。`global/*` 只适用于下表明确的管理或只读权限，不代表处置授权。内置权限模板由版本化代码/数据库迁移维护；首期平台管理员可分配预定义角色，不可在线改写角色权限。

| 角色 | 允许的功能 | 资源范围 | 禁止事项 |
| --- | --- | --- | --- |
| `platform_admin` 平台管理员 | 用户管理和预定义角色分配、系统配置、资产/授权审批及数据源维护；全局只读查看告警、事件、运行状态和审计 | 管理类权限全局；所列查询权限全局只读 | 响应申请/审批/执行、模型发布/回退；不可用管理员身份绕过策略 |
| `asset_source_admin` 资产与数据源管理员 | 资产/授权申请、数据源/映射及关联传感器登记、配置和健康维护 | 显式授权的资产和数据源 | IAM、授权审批、事件研判、响应审批、模型发布、响应执行 |
| `security_analyst` 安全分析员 | 查看告警/事件/证据、添加研判并按状态机更新事件、提交处置申请 | 显式资产/数据源范围 | IAM、审批、策略批准、直接执行、模型发布 |
| `response_approver` 响应审批员 | 查看审批所需目标和影响摘要，批准或拒绝待审批动作 | 审批任务所属且当前仍获授权的资产 | 审批本人申请、创建同一动作、直接执行或修改策略 |
| `model_operator` 模型操作员 | 登记候选模型元数据、提交验证并查看结果 | 模型注册范围 | 训练/推理、批准/发布模型、资产处置 |
| `model_releaser` 模型发布审批员 | 独立审查模型发布申请的元数据 | 模型注册范围 | 训练/推理、激活/实际发布模型、资产处置；批准本人发起的申请 |
| `auditor` 审计只读用户 | 只读查询审计和复盘信息 | 显式审计范围 | 业务写入、身份管理、审批、处置、模型发布 |

连接器、传感器和响应适配器不是人工角色：连接器只写指定数据源；传感器只读取自身绑定资产的有效配置并上报心跳/健康/获准流记录；响应适配器只接受策略引擎签发的结构化动作。三者均无控制台会话，也不能相互冒用身份。

权限由稳定键表示，例如 `iam.user.manage`、`iam.role.assign`、`asset.manage`、`asset.authorization.approve`、`source.manage`、`event.read`、`event.investigate`、`action.request`、`approval.decide`、`model.candidate.manage`、`model.release.request`、`model.release.approve` 和 `audit.read`。资产管理员只能提交待审批授权，平台管理员负责独立批准；同一用户不能申请并批准。`response.policy.manage` 不授予任何角色；策略维护按 M6（V15）拆为 `response.policy.draft`（`security_analyst`）与 `response.policy.approve`（`response_approver`），起草人不能审批；无有效策略时响应请求必须拒绝。敏感操作须由领域服务二次校验；高影响操作的申请人与审批人必须不同。

列表必须先在数据库应用范围过滤再分页。事件只有在全部关联资产、数据源及证据均在主体范围内时可见；存在范围外关联对象或无法判定归属时整条拒绝，不提供部分事件。范围外单资源查询返回 `404`，避免泄漏对象存在性；越权写入返回 `403` 并写审计。实际动作还须独立检查资产登记、授权有效期、策略、适配器能力、TTL、保护目标及安全回滚条件。

## 2. 模块划分

### 2.0 当前后端实现状态

- 已实现：Spring Security 浏览器会话、CSRF、BCrypt 登录、登录失败持久限速、退出与角色变更会话撤销；用户分页/创建、内置角色只读查询及角色范围整体替换；资产范围只读查询；追加式审计的范围查询。
- IAM 路由通过稳定权限键和 Spring 方法授权保护；资源范围不能由请求携带权限声明绕过。资产查询在 SQL 中将角色权限与该条角色绑定范围同时匹配；范围外 ID 返回 `404`。
- `audit_resource_scope` 采用全关联可见规则：范围型审计员只看到所有关联资源都在其 `audit.read` 角色范围内的记录；无资源范围的系统审计只向获全局审计权限的主体开放。审计 API 只读，不提供更新/删除端点。
- 用户创建不自动附加角色；只能整体替换为版本化内置角色模板。不能修改 `sys_role_permission` 或在线编辑内置模板。自我角色变更被拒绝，最后一名 active 全局平台管理员不能被移除；`admin` 账号绑定受到额外保留约束。
- 已新增资产登记、范围内更新和待审批授权生命周期，以及数据源登记/范围过滤/更新、draft 映射版本和独立授权审批。平台管理员不能借全局只读权限执行响应或模型发布。
- 已新增 connector 专用无状态机器凭据和幂等批次写入，以及 sensor 专用身份、配置、心跳、健康窗口和契约化流批次路由；凭据只返回一次。sensor 接入要求有效配置/映射、来源—资产绑定、序号和服务端字段校验，原始请求体在 JSON 解析前限制为 1 MiB。特征契约由资源文件驱动，在线契约为 `unsw-nb15-flow-v4`（v3.1 仅离线回放）；Java 侧提供 UNSW CSV 回放、100 流事件时间窗口和契约驱动的 Feature Builder，不执行单位猜测或 ONNX 图外派生。M2 已实现批次 outbox 消费拓扑、手动 ack、消费幂等台账、5 次有界 TTL 重试和死信记录；M3 在消费事务内按激活模型本机推理并写 `inference_request`，M4 随后生成告警并关联事件。macOS Go 传感器已完成 G2 对拍与本机影子运行。
- 已实现告警和事件范围读取、事件状态迁移和追加研判时间线；事件必须全部关联资源可见，不返回局部证据。
- 已实现模型候选元数据登记、ONNX 制品校验、范围内读取、独立发布申请审查和显式本机激活。候选元数据不可覆盖；发布审批不自动激活。漂移窗口计算（默认关闭）、告警标注与第二人复核、数据源影子报告已实现（V16）；训练任务编排与远端推理未实现。
- 已实现响应动作申请幂等台账、审批查询/决定和申请人动作详情。策略经 `/api/v1/response-policies` 起草、提交、由他人批准后生效（M6）；申请要求匹配 active 策略 allowlist、TTL、资产范围及当前有效授权。执行端点只记审计并返回 `ACTION_EXECUTION_UNAVAILABLE`，不写执行表或调用外部适配器。
- 用户冻结/更新、自助改密和其他业务域 API 尚未实现。规划表格中的功能不可视作交付能力。

### 2.1 主机传感器与采集健康

- 管理安装于 Mac/Windows 获授权主机上的软件传感器身份、版本、能力、接口范围和最后心跳。
- 下发版本化采集配置：允许接口/过滤范围、流超时、时间窗、字段契约、采样和元数据留存策略；变更可审计且支持回滚配置版本。
- 采集健康包含在线状态、最近数据时间、接收/丢弃计数、队列深度、CPU/内存摘要和特征构建错误。
- 传感器只观测本机操作系统/接口可见流量。全网镜像/导出只在现有网络设备支持且已授权配置时接入。
- 验收：传感器失联、特征积压或丢包显著时显示保护降级；传感器不可冒充其他资产或读取超授权范围配置。

### 2.2 在线流特征与检测

- 对主机可见流量生成有界流记录/滑动时间窗统计，记录采集时间、特征契约版本和完整性。
- 使用确定性方向/服务规则和冻结的自训练分类器形成互补检测信号；模型只分析满足特征契约的样本。
- DoS 检测组合可解释的速率/连接数阈值和训练模型标签支持的分类结果；不把流量分类等同于上游 DDoS 缓解。
- 传感器过载时有界缓存、背压、采样/丢弃统计和降级告警；RabbitMQ 不承载逐包数据。
- 验收：流超时、乱序、重复、特征缺失、处理过载和模型超时都有明确结果；正常业务策略不由模型分数单独覆盖。

### 2.3 主机防火墙动作

- 为操作系统配置独立的最小权限适配器；首期只实现经验证的本机临时阻断及定时解除能力。
- 每个动作绑定资产、对端标识、方向、端口/协议、来源告警、策略版本、TTL、幂等键和回滚标识。
- 仅追加窄范围临时阻断，不刷新默认策略、不清空或覆盖既有规则；排除控制面、管理会话、默认网关等保护目标，并保留本机/带外恢复方案。
- 只有操作系统适配器明确支持且经测试的限速能力才可展示/启用；首期可验收的自动动作以限时阻断及自动过期为主，否则只告警，不伪称限速。
- 对共享出口、关键管理连接、循环阻断风险设置保护清单；适配器断连或控制面失联时不得接受未经验证的新动作。
- 验收：只影响目标主机；规则按时过期；默认放行策略和既有防火墙规则不被覆盖；管理通道不被误封；重复请求不重复变更；失败可以人工接管；所有变更可审计。

### 2.4 模型漂移与受控离线再训练

- 按时间窗统计特征分布、质量拒绝率、类别/分数变化、正常流人工误报、传感器丢弃率和数据源变化。
- 对漂移仅创建观察告警，不自动改变阈值或模型权重；保留时间窗与当前模型版本关联。
- 人工确认样本及标签依据进入隔离反馈集；支持去重、来源追溯、撤销错误标签和训练用途审批。
- 管理员可为 Windows 离线训练环境创建候选训练任务；结果须导入报告、通过测试集/DoS/误报/兼容性门禁和人工审批后才可发布。
- 不提供在线增量拟合、伪标签自训练、告警直接作为真值或自动替换生产权重。
- 验收：训练任务的数据集版本和样本清单可追溯；候选失败不影响当前活动模型；新模型发布和回退可审计。

### 2.5 身份、角色与授权范围

- 登录、会话、角色/权限配置、API 客户端身份及连接器凭据引用管理。
- 为用户、数据源、资产和执行适配器绑定范围；范围变更产生审计记录。
- 支持冻结用户、轮换客户端密钥引用和紧急撤销处置授权。
- 验收：未授权用户不能枚举或操作范围外资源；连接器身份不能调用处置接口。

### 2.6 资产与授权登记

- 维护资产标识、类型、环境、关键性、标签、所有者、授权状态及生效/到期时间。
- 将靶场资产与授权实网资产分区标记；处置策略只引用已登记资产/标签。
- 保存授权证明的安全引用和审批记录，不在普通业务字段中保存敏感证明原文。
- 验收：授权过期、资产停用或靶场边界变化后，相关自动动作被拒绝。

### 2.7 数据源与接入批次

- 管理公开数据集、文件导入、回放源和授权被动遥测连接器。
- 记录字段清单、模式版本、授权范围、采集状态、最后成功时间和质量统计。
- 批次支持校验预览、接受/拒绝统计、重复提交幂等和失败原因下载。
- 验收：格式错误、来源未登记、批次重复和授权失效均有稳定状态与可审计结果。

### 2.8 规范化与特征质量门禁

- 维护来源模式到规范事件/流量字段的映射版本、单位和转换定义。
- 分别校验必填字段、类型、范围、时间戳、枚举、字段覆盖和来源可信度。
- 将记录分为可推理、待人工研判、拒绝三类；保存校验问题和映射版本。
- 验收：缺少模型必需字段或单位不匹配的记录不会被送入模型；修复映射后可重放批次。

### 2.9 模型注册、验证与推理路由

- 管理候选/已批准/已激活/已停用模型版本、制品位置、manifest、哈希、评估和运行时信息。
- 检查 manifest、权重哈希、特征顺序、预处理、标签、阈值、运行时与部署模式兼容性。
- 统一推理接口支持本机模型运行时和远端推理 API；保留模式、端点标识、模型版本和健康状态。
- 提供单条/批量推理、影子对比和健康检查；不同版本切换须显式审批并记录。
- 验收：校验失败模型不可激活；服务超时/版本不一致明确失败，不静默使用旧版本。

### 2.10 检测告警与事件研判

- 根据模型结果和确定性规则创建告警；记录输入摘要、数据质量、模型/阈值版本和证据引用。
- 按资产、时间窗、来源及关联标识将告警与安全/终端日志归并为事件。
- 展示事件状态、影响资产、证据时间线、关联告警、研判结论、处理人和处置历史。
- 支持确认、误报、升级、合并、拆分、分派和关闭；每次状态变化可追溯。
- 验收：告警能回溯到原始来源、特征映射和模型版本；重复输入不会产生无界重复事件。

### 2.11 风险评估与安全建议

- 以版本化、可解释规则综合模型分数、数据可信度、资产关键性、告警频度和独立证据数。
- 建议由批准的处置手册/模板生成，注明触发证据、适用条件、风险、时效和回滚方式。
- 首期趋势页只呈现已发生告警的历史统计；未来攻击预测为未实现的扩展能力。
- 验收：低质量/不完整数据不能被展示成高置信结论；用户可查看风险分级的组成项。

### 2.12 响应策略、审批与执行

- 策略按环境、资产范围、动作白名单、风险条件、时限、频率和审批要求匹配。
- 执行前复核授权状态和目标边界；默认拒绝未登记目标、任意命令、任意 URL 和参数注入。
- 支持策略内自动执行、人工审批、拒绝、撤销、执行超时和回滚；适配器凭据最小化隔离。
- 执行台账记录请求、策略快照、操作者、审批、适配器回执、状态和回滚句柄。
- 验收：越权请求 fail-closed；重试不重复执行；失败或过期动作有明确补偿/人工接管状态。

### 2.13 数据回放与隔离靶场

- 管理回放场景、文件/样本范围、运行速率、重复运行标识、当前进度和结果摘要。
- 支持暂停/继续/终止回放；将回放产生的事件标记为演练数据，与授权实网事件隔离展示。
- 靶场的外网隔离属于部署网络控制，不以 UI 选项代替；靶场动作仅调用靶场适配器。
- 验收：回放可重复；相同输入和模型版本可比较；运行不会向未授权目标发出流量。

### 2.14 报告、审计与运行健康

- 报告包含数据范围、模型/策略版本、告警与事件、处置和审计摘要，导出时执行脱敏。
- 审计覆盖登录、权限变更、数据接入、模型激活、策略编辑、审批、执行和回滚。
- 健康视图展示数据源、队列、推理端、模型版本、适配器和待办任务状态。
- 验收：审计记录不可由普通业务接口修改或删除；关键失败和积压能被发现。

## 3. 优先级与阶段交付

| 阶段 | 交付能力 | 退出条件 |
| --- | --- | --- |
| A：模型与传感器基线 | 自训练离线分类器、Mac/Windows 软件传感器、特征契约、在线冻结推理、健康状态 | 基准与传感器 golden fixtures 一致；有延迟/丢弃/质量基线 |
| B：检测与受控防御 | 告警事件、主机临时防火墙阻断/到期解除、审批/审计、隔离靶场回放 | 仅影响授权主机，越权/重复/过期/回滚测试通过 |
| C：漂移与迭代 | 漂移窗口、人工反馈集、Windows 离线候选训练、审批发布/回退 | 候选数据/模型可追溯，不发生在线或未经审批换权重 |
| D：授权范围扩展 | 更多已授权主机传感器或现有网络设备导出源 | 每个数据源单独完成可见性、特征、性能和授权验收 |

阶段 A-C 可形成包含实时采集、模型检测、防护和模型治理的完整毕设闭环，但不等于生产级全网防护。两台主机只能验证各自可见范围；更多资产必须安装传感器或通过已有网络设备授权导出。

## 4. 不属于首期功能

大语言模型训练/微调、模型在线自训练、原始包深度检测、完整 EDR、通用 SIEM/SOAR、未经验证的攻击预测、自由编排脚本、面向互联网的主动扫描或攻击生成均不纳入项目范围。
