## 4. 接入顺序

1. P3 冻结候选与 P4 本地接入已完成；P5 已通过回环 lab 的全入站签名及主要恢复矩阵，继续收口剩余必需组合与 P4 联合签发；当前 P6 候选不作为 G3 候选，见 P6 诊断。部署前验证真实业务库迁移与 broker。
2. P6 在 L1 test 上判定 G1/G2，报告 L2/L3。
3. P7 接入真实模型完成 G3 闭环。
4. P8 按资产授权启用已通过的类别；新路径失败时显式暂停并核对本机规则，旧 v4 路径不接管 v5 自动动作。
