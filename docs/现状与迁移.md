1. P1确认数据及目标平台动作可行，给不支持平台明确结论；不先写完业务系统再发现无法执行。
2. P2新建v5因果提取器和机器协议，保留旧路径作回归。rc候选可以根据探针修订，冻结后任何语义变更换版本。

4. P4向前追加数据库和/api/v2，不原位破坏/api/v1。权限映射、UUID、资产范围、状态与审批逐项验证。
5. P6锁定最终模型和完整策略，P7在隔离环境完成真实模型→动作→恢复。期间仍需区分研究结果与已验证能力。
6. P8仅按明确授权的资产/能力绑定切换；旧模型/策略不能静默承接v5自动执行。切换失败暂停对应新能力，先核对本机规则，再恢复已验证版本。
